# Plataforma que cai

Projeto Unity 2D (2022.3) em que a plataforma começa parada, como Kinematic e sem gravidade. Quando o jogador encosta nela, o script `PlataformaMovel.cs` faz ela andar para a direita em velocidade constante por 5 segundos. Depois ela para, vira Dynamic e cai com a gravidade, e só ativa uma vez. Para testar, abra `Assets/Scenes/Cena.unity`, dê Play, ande com A/D ou as setas e pule com Espaço.
